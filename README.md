# Robotics Learning Journey

A structured, simulation-first path from beginner foundations to research-oriented robotics engineering, with emphasis on ROS 2, robot perception, computer vision, SLAM, and autonomous systems.

## Learning goals
- Build a strong foundation in robotics mathematics, geometry, probability, and kinematics.
- Become comfortable developing and debugging ROS 2 systems.
- Design robot models and simulation environments using SolidCraft and Gazebo.
- Build perception pipelines with OpenCV, depth cameras, point clouds, and modern vision models.
- Understand visual odometry, SLAM, localisation, navigation, and manipulation.
- Complete an integrated mobile-robot capstone and document the work publicly.

## Study commitment
Plan for approximately **15–20 hours per week**. The 48-week roadmap is a structured foundation, not a guarantee of mastery; spend extra time where implementation or mathematical understanding is weak.

## Working principles
1. Prefer simulation before purchasing hardware.
2. Learn concepts by implementing small, testable systems.
3. Keep a record of errors, debugging steps, and design decisions.
4. Read papers alongside implementation, not instead of it.
5. Record evidence: code, launch files, screenshots, short demos, and concise technical notes.

## Environment note
Check the installed ROS 2 distribution and matching Gazebo integration before installing packages. Do not mix packages from different ROS distributions. The learning plan uses the ROS 2 documentation for the distribution installed on your machine.
